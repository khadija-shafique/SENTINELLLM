# SENTINELLLM
Automated AI red-teaming platform that stress-tests LLMs for prompt injection, jailbreaks, system-prompt leakage and sensitive-data disclosure via 29 attack payloads (English, Roman Urdu, multilingual, role-play). Verdicts blend deterministic rules with a locked Groq LLM judge, map to OWASP LLM Top 10, and score risk 0–100.
